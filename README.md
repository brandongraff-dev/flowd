# flowd

**Money follows what works.** flowd is the open creator market for app growth: app teams fund *bounties*, creators compete for them, models score and QA every video, and money flows through escrow and a double-entry ledger to whatever actually drives views, installs, trials and paid subscriptions.

| | |
|---|---|
| **Web** (`apps/web`) | Next.js 16 · React 19 · Tailwind v4 — marketing site, free tools, brand dashboard, creator portal, admin, mock API |
| **iOS** (`apps/ios`) | SwiftUI creator app · iOS 17+ with Liquid Glass on iOS 26 · Live Activity widget · generated with XcodeGen |
| **Contract** (`packages/contract`) | Domain model, TypeScript types, OpenAPI, deterministic fixtures, golden test vectors |
| **Tokens & brand** (`packages/tokens`, `brand/`) | Design tokens, logo system (flat), brand book |
| **Backend** (`supabase/`) | Postgres schema, RLS, settlement functions, edge functions |
| **ML** (`services/ml`) | FastAPI service: Hook Score, Flow Score, auto-QA, fraud, matching, CPM suggestion (605 tests) |

## Run the web app

```bash
npm run sync                 # copy tokens + fixtures + types into the apps
cd apps/web && npm install && npm run dev   # http://localhost:3000
```

## Run the iOS app

Needs macOS + Xcode 26. No Mac? GitHub Actions builds and runs it in the iOS Simulator for free on this public repo (see `.github/workflows/`).

```bash
brew install xcodegen
npm run sync
cd apps/ios && xcodegen generate && open Flowd.xcodeproj
```

## Demo data

Everything runs against deterministic fictional fixtures (no real brands, people or photos) generated by `packages/contract/scripts/generate-fixtures.mjs`. Integrations (TikTok, Instagram, Stripe, RevenueCat, …) are adapter interfaces with realistic mocks.
