## 2. Why the UI looks bad (diagnosis) and the fix
Seen in the iOS screenshots and web gallery:
1. Gradient aurora backgrounds everywhere (purple→blue→teal) read as generic "AI app"; they muddy contrast and fight the content.
2. Glass cards on a gradient have low separation; everything is the same dark-navy rectangle with the same radius → weak hierarchy.
3. Huge empty header space and an oversized system large-title; content starts too low.
4. Too many accent colours at once (mint, cyan, ember, violet, blue) with no single primary.
5. Type scale is flat: figures and labels are similar weight; little rhythm/density; hero numbers are fine but surrounding text is bland.
6. Placeholder-feeling stat cards (icon + label + number) repeated.
FIX DIRECTION — "Flat Ink": 
- Remove ALL gradients and the aurora/glow/orbs (UI, charts, CTA buttons, headline gradient text, tier medallions' gradients can become solid rings). Background = solid (dark: #08112A/#030921 ink; light: #F3F7FF ice). Surfaces = solid raised fills with 1px hairline borders, NOT blurred glass. Keep real Liquid Glass ONLY for the iOS tab bar/toolbars/sheets (system look) — nowhere else.
- One primary accent: mint (#18DF9B dark / #20B27C light) for money and primary actions; ink/ice for text; a single neutral for secondary. Drop violet/cyan/ember as decoration (ember only for urgency, rose for danger).
- Layout: tighter header (small inline title), 8/12/16 spacing rhythm, 2-level type hierarchy (hero figure 40–48 / section 20 / body 15 / caption 12), use dividers and grouped lists instead of cards-in-cards, bigger tap rows, real data density.
- Where: packages/tokens/tokens.json + build.mjs (set gradients/aurora to solid, regenerate: `node packages/tokens/build.mjs && npm run sync`), apps/ios/Flowd/DesignSystem (AuroraBackground → solid; FlowdCard → solid surface; FlowdGlassButtonStyle primary → solid mint), apps/web/src/components/{glass,ui} + styles. Logo/app icon are ALREADY flat (brand/logo, brand/src/build-logos.mjs).
- Use the installed skills (invoke with the Skill tool; apply, do not just read): interfaces:better-ui, interfaces:better-layout, interfaces:better-typography, interfaces:better-colors, apple-design, emil-design-eng, interfaces:better-accessibility; dataviz for charts; write-swift for Swift. Do the fix on ONE screen first (iOS Home), screenshot it on CI, get the user's approval, THEN propagate.
